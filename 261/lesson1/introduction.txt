M5Stack Stick S3 IoT Engineering & Business Curriculum (Lessons 1–15)

This technical curriculum provides an end-to-end hands-on pathway for building, securing, and deploying enterprise-grade Internet of Things systems using the M5Stack Stick S3 (ESP32-S3). The technical progression aligns with the Master of Business Administration (MBA) IoT for Business curriculum (ADE644/AGE644).

Hardware & Toolchain Reference

1) Microcontroller: ESP32-S3-PICO-1 (Dual-core Xtensa LX7 @ 240 MHz, 2.4 GHz Wi-Fi, BLE 5.0)
2) Onboard Peripherals: 1.14" ST7789v2 LCD (135x240), BMI270 6-axis IMU, SPM1423 PDM microphone, AXP2101 PMIC, RTC, IR transmitter, 2x user buttons (BtnA, BtnB)
3) Expansion: 1x Grove I2C/GPIO port, 8-pin extended GPIO header
4) Core IDE: Visual Studio Code with PlatformIO Core CLI
5) Language & Framework: Embedded C++ / Arduino Framework via Espressif32 Platform
