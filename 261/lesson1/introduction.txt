Lesson 1: Setting Up the Software & Development EnvironmentCore Focus: Establishing a reproducible, enterprise-ready embedded development pipeline on Visual Studio Code and PlatformIO.Business & Academic Linkage: Hardware development platforms, embedded toolchains, and zero-cost open-source developer tooling (ADE644 Lesson 6).   Hands-On Activities & ProceduresVS Code & PlatformIO IDE Installation:Download and install the latest stable build of Visual Studio Code.Open the VS Code Extensions Marketplace (Ctrl+Shift+X / Cmd+Shift+X), search for PlatformIO IDE, and install. Allow the PlatformIO Core CLI engine to complete initialization.USB Drivers & Port Enumeration:Install the Espressif ESP32-S3 USB CDC drivers (or CH9102/CP210x virtual COM drivers depending on OS).Connect the M5Stick S3 to the host workstation via a high-quality USB-C data cable.Open the OS Device Manager (Windows) or execute ls /dev/tty* (macOS/Linux) to verify that a valid COM port appears (e.g., COM5 or /dev/ttyACM0).Git & Environment Verification:Verify Git CLI is installed: git --version.Create a local project root directory: M5StickS3_IoT_Journey/.Deliverable Checkpoint: Screenshot of PlatformIO Home screen detecting the connected ESP32-S3 COM port and active toolchain terminal.
